# Commit and pull request attribution policy

This policy applies to every AI assistant and coding agent working in this repository, including Claude, Codex, GitHub Copilot, Cursor, Gemini, and other tools.

- Do not add AI attribution to commit subjects, commit bodies, trailers, pull request titles, or pull request descriptions.
- Do not add AI `Co-authored-by` trailers, bot co-author credits, "Generated by", "Created with", "Assisted by", agent signatures, promotional links, or session links to commits or pull requests.
- Describe the actual change, its purpose, and relevant validation in commit messages and pull requests.
- Before submitting, inspect the complete commit message and pull request title/body and remove any automatically inserted AI attribution.
- Use the existing authorized Git identity. Do not impersonate a person, invent human authorship, or change author/committer identities to hide platform-recorded activity.
- Preserve genuine human contributor credits, required legal notices, third-party license attribution, and technical references to AI when relevant to the change itself.
- Do not rewrite existing history or edit previously submitted commits or pull requests solely for this policy unless explicitly requested.

Claude Code's project settings disable automatic commit and pull request attribution. Other agents must follow this policy through their repository instructions. These files do not override platform identity records or tools that ignore repository instructions.
